# Certinia — quick primer for the UKG ESE CX role

Tasos mentioned Certinia familiarity would be helpful (relayed via Steve).
Ian doesn't know it directly. This is the honest fast-ramp primer.

## What it is

- Formerly **FinancialForce**, rebranded to Certinia in early 2023.
- A services-as-a-business platform **built natively on the Salesforce
  platform** — uses Salesforce's data model, security, infrastructure;
  custom objects and apps on top. Not a separate system that
  *integrates* with Salesforce; it lives inside it.
- Headquartered in San Francisco.

## Core products (relevant ones)

- **PSA — Professional Services Automation** (the main product): project
  management, resource management, time/expense tracking, billing,
  invoicing for services delivery work
- ERP (financial close, billing, revenue recognition)
- Customer Success
- Services-CPQ

## Likely UKG use case

The "CX" customer for this PO role is internal services teams that
support customers using UKG products. Those teams almost certainly run
their delivery work in Certinia PSA: services consultants running
customer implementations, project tracking, time against engagements,
billing. That's the workflow surface Ian would be intaking and
translating for.

## Why Ian's existing fluency bridges into it

- Certinia inherits the Salesforce platform Ian operated in during the
  UTA upgrade program (case/SR object model, approval workflows, the
  operational layer).
- PSA concepts (resource utilization, project profitability, milestone
  billing) are new vocabulary on top of a platform he already knows.
- Genuinely a learnable lift, not a fundamentally new system.
