# Day 1 Tech Stack — Deltek Senior Manager, AI Adoption & Enablement

Companion to `Deltek_30_60_90_Plan.md`. Three categories: what you carry in personally, what you ramp on before Day 1, what you absorb in Week 1.

## Personal stack you carry in

### The accelerator
- **Claude Code on macOS.** Existing operating system. Drafts every observation memo, 1:1 summary, decision doc, and dashboard prototype.

### The thinking layer
- **Obsidian** for the observation log and 1:1 notes. Local-first Markdown, no vendor lock-in, Claude Code reads it natively. Better than Notion for this role because it's private, fast, and survives any IT/security policy at Deltek.
- **One simple spreadsheet** for the relationship map (~20 people across L&D, AI Platform, vertical leads, panelists, executives). Fields: role, what they care about, what they own, friction points named, next-touch cadence.

### The async layer
- **Loom personal account.** The non-negotiable tool for bridging Makati/India. A 90-second Loom replaces a 30-minute meeting in maybe 60% of cases for the global team. Free tier is enough to start.
- **World clock app on Mac menu bar** (Menu World Clock or built-in macOS) showing Makati, Bengaluru, Boston simultaneously. Friction-free time-zone awareness from Day 1.

## Deltek stack to ramp BEFORE Day 1

The platforms the JD names as required. Walking in already literate cuts ramp time materially.

### Microsoft 365 — the real ramp

- **Viva Suite (Topics, Engage, Learning).** Microsoft Learn has free structured paths. ~3 hours gets you literate in all three. The genuine gap from operator-level Microsoft 365 history.
- **SharePoint information architecture.** You've used it, but the architecture layer matters for how P&T content lives. Microsoft Learn modules.
- **Power Automate basics.** Flows, triggers, connectors. JD mentions it explicitly. ~2 hours of structured intro on Microsoft Learn.
- **Teams.** Already known. Skip.

### Achievers recognition platform
- Achievers' own resource center has free webinars and documentation. ~1-2 hours covers the data model, recognition types, reporting structure, and admin workflows. Mandatory literacy because the role administers this.

### Deltek Talent Management
- Deltek's own product docs explain the platform you'll be partnering with. The Learning Path / class schedule integration is core to the onboarding work in Phase 3 of the 30/60/90.

## Deltek stack to absorb in Week 1

These can't reasonably be prepped externally — internal to Deltek's actual deployment.

- **Internal AI tooling already deployed.** Likely Microsoft Copilot at minimum, possibly GitHub Copilot for engineering, possibly Claude or ChatGPT Enterprise. The AI Platform team lead's 1:1 in Week 2 surfaces the full inventory.
- **Jira and Confluence as Deltek uses them.** Standards may differ from UKG's. Read existing structures as data, not as things to fix.
- **Whatever BI tool Deltek standardized on.** Most likely Power BI given the Microsoft alignment. Confirm in Week 2 and start learning the existing dashboards.
- **Existing onboarding LMS flows in Deltek Talent Management.** Read every flow before proposing anything.

---

## Optional but useful for the role

- **Survey tooling.** Microsoft Forms is the default. Used for the quarterly "what would you stop doing if this tool went away tomorrow" surveys from the measurement framework.
- **One AI-adoption-specific vendor literacy.** Adoptive, Pulse for AI, PromptStack are emerging adoption-measurement platforms. Don't buy anything; just know they exist for Phase 3 piloting decisions.

---

## What NOT to bring

- **A second productivity tool stack** (Linear, Asana, Notion + Coda + Airtable). You'll work in whatever Deltek uses. Personal tools that overlap with enterprise tools create friction.
- **A personal AI subscription you'll evangelize** (e.g., insisting on Claude over Copilot). Use what Deltek deploys. Personal Claude Code is fine because it's your private accelerator; pushing a different enterprise tool on Day 1 reads as not-here-yet.
- **A heavyweight observation framework.** The Obsidian + spreadsheet combo is enough. No 12-template knowledge-management system on Day 1.
